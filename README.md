# 📰 Daily Current Affairs

A responsive news and current affairs website built using **HTML, CSS, and JavaScript**. It helps readers explore news across multiple categories through a clean and user-friendly interface.

## 🌐 Live Website

👉 **[Visit Daily Current Affairs](https://dailycurrent-affairs-ed19a6.netlify.app/)**

## ✨ Features

- 🗞️ **Multiple News Categories** — National, International, Politics, Economy, Technology, Science, Sports, Education, and more.
- 🔎 **Search Functionality** — Find news and articles easily.
- 📈 **Trending News** — Discover important and popular stories.
- 📰 **Detailed Article Pages** — Read individual news articles.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 🖼️ **Image Slider** — Browse featured news visually.
- 📱 **Responsive Design** — Designed for a convenient browsing experience across different screen sizes.
- 📤 **Article Sharing** — Share news with others.

## 🛠️ Technologies Used

| Technology | Purpose |

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shelkepranay3-gif/daily-current-affairs.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No build tools are required for this basic HTML, CSS, and JavaScript project.
